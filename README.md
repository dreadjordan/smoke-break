sometimes you just need a break

## features

- live-action cigarette
- desktop looks (and sounds) far away while you're stepped back
- can be set on automatic timer

Press any key during a break to end it early. Right-click the icon for settings.

Tested only on macOS (version 27).

## installation

Download the installer from the releases page.

**macOS:** open the `.dmg` and drag Smoke Break to Applications. 

it isn't notorized, so expect permission pop-ups.

**Windows:** (untested) run the installer. it isn't code signed, expect warnings.
